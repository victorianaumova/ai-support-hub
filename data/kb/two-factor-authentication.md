## 2FA is mandatory

Every Tallybridge account must use two-factor authentication (2FA). When you log in, you enter your password and a code. You get the code in one of two ways:

1. an authenticator app, or
2. SMS.

## ERR-5004: 2FA not set up

If two-factor authentication is not set up on your account, the app shows ERR-5004.
Set up 2FA with an authenticator app or SMS before you continue.

## ERR-5003: 2FA code invalid

The 2FA code you entered is not valid.

1. Make sure you use the newest code.
2. If you use an authenticator app, check that you use the entry for Tallybridge.
3. If you use SMS, wait for the new SMS and enter that code.
4. Enter the code again.

## Never share your 2FA code

Your 2FA code is only for you. Tallybridge staff never ask for your 2FA code. Not in chat, not by email, not by phone. If someone asks you for your code, do not give it. Contact us.

## If you get a code you did not ask for

If you get a 2FA code by SMS and you did not try to log in, someone may know your password. Do not share the code. Contact us at once.
